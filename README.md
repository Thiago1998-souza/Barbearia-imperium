# 💈 Barbearia Imperium

Projeto desenvolvido para fins acadêmicos, consistindo em uma interface web para uma barbearia fictícia. O sistema apresenta os serviços oferecidos, tabela de preços e informações de contato.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação de conteúdo semântico.
- **CSS3**: Estilização, layout responsivo e design visual.

---

## 📌 Funcionalidades

- Apresentação da barbearia e história.
- Catálogo de serviços e preços.
- Formulário de contato/agendamento fictício.
- Design adaptado para navegação web.
